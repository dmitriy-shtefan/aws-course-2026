# Бази даних: Amazon DynamoDB

Для виконання завдань використовуйте вже створену таблицю `Music`:

- **Partition Key:** `Artist` типу `String`;
- **Sort Key:** `Song` типу `String`.

### Завдання 1. Додавання записів через AWS CLI

Додайте до таблиці `Music` два власні записи про музичні композиції за допомогою AWS CLI.

Вимоги:

1. Для додавання кожного запису використайте команду `aws dynamodb put-item`.
2. Кожен запис повинен містити:
   - `Artist`;
   - `Song`;
   - `Album`;
   - `Year`.
3. Значення `Artist` і `Song` мають утворювати унікальну комбінацію для кожного запису.
4. За допомогою команди `aws dynamodb query` знайдіть один зі своїх записів за значеннями `Artist` і `Song`.
5. Переконайтеся, що команда повернула правильний запис.
6. За допомогою команди `aws dynamodb scan` без фільтрів виконайте повне сканування таблиці та перегляньте всі записи.

Що здати:
- один скріншот термінала з командами AWS CLI та результатами операцій `Query` і `Scan`.

### Завдання 2. Додавання записів через Python SDK

Напишіть Python-програму, яка за допомогою AWS SDK додає до таблиці `Music` ще два власні записи про музичні композиції.

Вимоги:

1. Використайте бібліотеку `boto3`.
2. Підключіться до таблиці `Music`.
3. Додайте два записи за допомогою методу `put_item`.
4. Кожен запис повинен містити:
   - `Artist`;
   - `Song`;
   - `Album`;
   - `Year`;
   - щонайменше один додатковий атрибут на власний вибір, наприклад `Genre` або `LengthSeconds`.
5. Обидва записи мають відрізнятися від записів, доданих через AWS CLI.
6. За допомогою методу `query` знайдіть один із доданих записів за значеннями `Artist` і `Song`.
7. За допомогою методу `scan` без фільтрів виконайте повне сканування таблиці.
8. Програма повинна вивести повідомлення про додавання кожного запису, результат пошуку та всі записи, отримані під час сканування.

Що здати:
- Python-файл із кодом програми.

> **Зверніть увагу:** повторне додавання запису з тією самою комбінацією `Artist` і `Song` замінить наявний запис у таблиці.
