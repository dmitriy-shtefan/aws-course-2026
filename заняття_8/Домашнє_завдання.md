# Обробка замовлень за допомогою AWS Lambda і DynamoDB

Створіть Lambda-функцію на Python, яка отримує дані замовлення, обчислює його загальну вартість і зберігає замовлення в DynamoDB.

Приклад вхідної події:

```json
{
  "order_id": "order-101",
  "customer_name": "Олена",
  "items": [
    {"name": "Клавіатура", "price": 1500, "quantity": 1},
    {"name": "Миша", "price": 700, "quantity": 2}
  ]
}
```

Вимоги:

1. Реалізуйте функцію `lambda_handler(event, context)`.
2. Перевірте наявність полів `order_id`, `customer_name` та `items`.
3. Обчисліть загальну кількість товарів і вартість замовлення.
4. Додайте до замовлення статус `NEW` і дату створення.
5. Збережіть замовлення в таблиці DynamoDB з Partition Key `order_id`.
6. Не перезаписуйте замовлення, якщо такий `order_id` уже існує.
7. У разі успіху поверніть код `201` та інформацію про створене замовлення.
8. Для некоректних даних поверніть код `400`, а для повторного `order_id` — `409`.

Результат надішліть у вигляді одного файлу:

- `lambda_function.py` — код Lambda-функції.

Перевірка в AWS-акаунті для виконання завдання є бажаною, але не обовʼязковою. Достатньо написати код функції без її розгортання та запуску в AWS.

Не записуйте AWS Access Key, Secret Access Key або Session Token у коді.
