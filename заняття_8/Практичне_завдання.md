# Створення мініатюр зображень за допомогою AWS Lambda та Amazon S3

Створіть Lambda-функцію на Python, яка автоматично створює мініатюру після завантаження зображення в Amazon S3.

Вимоги:

1. Створіть два S3 buckets: один для оригінальних зображень, інший — для мініатюр.
2. Налаштуйте для першого bucket тригер події `ObjectCreated`, який запускає Lambda-функцію.
3. Отримайте з події назву bucket і ключ завантаженого об’єкта.
4. Завантажте зображення з S3 у тимчасову папку Lambda `/tmp`.
5. За допомогою бібліотеки Pillow створіть мініатюру розміром не більше `200 × 200` пікселів зі збереженням пропорцій.
6. Збережіть мініатюру в другий S3 bucket. До назви файлу додайте префікс `thumbnail-`.
7. Додайте обробку помилок і логування основних етапів роботи функції.
8. Надайте execution role Lambda лише необхідні дозволи на читання з першого bucket і запис у другий.

Перевірте роботу функції, завантаживши файл формату JPEG або PNG у перший bucket. Після виконання функції мініатюра повинна з’явитися в другому bucket.

Результат надішліть у вигляді одного файлу:

- `lambda_function.py` — код Lambda-функції.

## Бонусне завдання

Створіть таблицю DynamoDB і після успішної обробки зображення збережіть у ній:

- назву початкового файлу;
- S3 URI оригінального зображення;
- S3 URI створеної мініатюри;
- дату й час обробки.

Не записуйте AWS Access Key, Secret Access Key або Session Token у коді.
