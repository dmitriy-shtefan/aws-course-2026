# Зберігання даних: Amazon S3. Частина 1

## Створення S3 bucket і завантаження файлів

### Завдання 1. Створення S3 bucket і завантаження файлів

Компанія хоче використовувати Amazon S3 для зберігання робочих файлів.
Потрібно створити новий S3 bucket і завантажити в нього два файли.

Вимоги:

1. Відкрийте сервіс Amazon S3 у AWS Management Console.
2. Створіть новий S3 bucket.
3. При створенні bucket вкажіть:
   - унікальне ім'я bucket;
   - потрібний регіон.
4. Після створення bucket відкрийте його.
5. Завантажте в bucket два файли.
6. Перевірте, що обидва файли відображаються в списку об'єктів.
7. Відкрийте властивості bucket і перевірте його основні параметри:
   - ім'я bucket;
   - регіон;
   - статус доступу.
8. Відкрийте список об'єктів і перевірте:
   - імена файлів;
   - розмір файлів;
   - дату завантаження.

Що здати:
- скріншот зі списком об'єктів усередині bucket, де видно два завантажені файли.

### Завдання 2. Налаштування публічного доступу до файлів

Компанія хоче опублікувати файли в S3 так, щоб їх можна було відкрити за посиланням без
використання AWS-акаунта. Потрібно налаштувати доступ до файлів через Permissions і Bucket Policy.

Вимоги:

1. Використовуйте bucket із попереднього завдання.
2. Відкрийте вкладку **Permissions**.
3. Перевірте поточні налаштування **Block public access**.
4. Змініть налаштування bucket так, щоб з'явилася можливість відкрити файли ззовні.
5. Налаштуйте **Bucket Policy** для публічного читання об'єктів.
6. Перевірте, що політику застосовано без помилки.
7. Відкрийте один із завантажених файлів за його URL.
8. Переконайтеся, що файл відкривається без авторизації в AWS.
9. Перевірте налаштування bucket:
   - Block public access;
   - Bucket Policy;
   - Object URL.

Що здати:
- публічне посилання на файл.

### Завдання 3. Публікація статичного сайту через Amazon S3

Компанія хоче опублікувати простий статичний сайт через Amazon S3.
Потрібно підготувати bucket, завантажити файли сайту й увімкнути режим Static website hosting.

Вимоги:

1. Створіть новий S3 bucket для сайту.
2. Підготуйте файли сайту:
   - `index.html`;
   - за необхідності `error.html`.
3. Завантажте файли сайту в bucket.
4. Відкрийте властивості bucket.
5. Увімкніть **Static website hosting**.
6. Вкажіть:
   - index document;
   - error document, якщо використовується.
7. Перейдіть у вкладку **Permissions**.
8. Налаштуйте доступ так, щоб сайт був доступний ззовні.
9. Відкрийте Website endpoint bucket.
10. Переконайтеся, що сайт відкривається в браузері.
11. Перевірте:
    - налаштування Static website hosting;
    - список завантажених файлів;
    - доступність сайту за Website endpoint.

Що здати:
- публічне посилання на сайт.
