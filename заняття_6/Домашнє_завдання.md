## Робота з Amazon S3 через AWS SDK for Python

### Створення резервної копії файлу в Amazon S3

Компанія хоче автоматизувати створення резервних копій файлів.
Потрібно створити Python-програму, яка завантажує файл в Amazon S3, показує
збережені об’єкти та перевіряє можливість завантажити файл назад.

Вимоги:

1. Використайте Python і бібліотеку `boto3`.
2. Створіть S3 client за допомогою AWS SDK for Python.
3. Отримайте від користувача:
   - ім’я наявного S3 bucket;
   - шлях до локального файлу.
4. Перевірте, що вказаний локальний файл існує.
5. Завантажте файл у bucket за допомогою `upload_file`.
6. Збережіть файл у bucket з ключем у форматі `backups/ім’я_файлу`.
7. Отримайте список об’єктів із префіксом `backups/` за допомогою `list_objects_v2`.
8. Для кожного знайденого об’єкта виведіть:
   - ключ об’єкта;
   - розмір у байтах;
   - дату останньої зміни.
9. Завантажте щойно збережений об’єкт з S3 назад на комп’ютер за допомогою
   `download_file` та збережіть його під новим ім’ям. 
10. Передбачте обробку помилок:
    - локальний файл не знайдено;
    - bucket не існує або недоступний;
    - AWS повернув помилку.

Не записуйте AWS Access Key, Secret Access Key або Session Token безпосередньо в коді.
Програма повинна використовувати облікові дані, налаштовані в середовищі запуску.

Результат надішліть у вигляді одного файлу:
- `solution.py` - код програми.
