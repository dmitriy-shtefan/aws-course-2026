## Завдання 1. Для простої AI-інтеграції команда обрала занадто складний шлях через SageMaker JumpStart

**Є:** розробникам потрібно додати в застосунок виклик готової генеративної моделі.

**Проблема:** команда обрала складніший шлях, хоча завдання не вимагає розгортання і тонкого налаштування моделі.

**Потрібно:**

1. Пояснити, чим відрізняються підходи Amazon Bedrock і SageMaker JumpStart.
2. Пояснити, чому вибір сервісу має залежати від типу завдання.
3. Запропонувати, який варіант виглядає більш доречним для цього сценарію.
4. Пояснити, як обґрунтувати цей вибір для команди.

## Завдання 2. Команда не може вирішити, чи використовувати Bedrock або SageMaker JumpStart

**Є:** проєкту потрібно додати в застосунок генеративну модель для роботи з користувацькими запитами.

**Проблема:** команда не може вибрати між Amazon Bedrock і SageMaker JumpStart і обговорює сервіси без розуміння відмінностей у підході.

**Потрібно:**

1. Пояснити, чим відрізняється Bedrock від SageMaker JumpStart.
2. Пояснити, для яких завдань краще підходить кожен із сервісів.
3. Запропонувати, який варіант доречніший для цього сценарію.
4. Пояснити, як обґрунтувати вибір архітектури для команди.
