# S3: надати партнеру тимчасовий доступ до прайсу

## Робоча ситуація

Партнер попросив прайс магазину. Бакет має залишитися приватним,
але партнеру потрібно дозволити завантажити один файл протягом п'яти хвилин.
Для вправи ви перевіряєте посилання самостійно, без надсилання іншій людині.

## Перед завданням підготувати

Власний приватний бакет, boto3 та право PutObject і GetObject для свого навчального префікса.
Python, boto3, тимчасові credentials Sandbox і дозволений регіон.

## Завдання

1. Створіть вигаданий `price.txt` із двома товарами й цінами.
2. Завантажте його через boto3 до `student01/short-tasks/price.txt`.
3. Через `generate_presigned_url` для `get_object` створіть посилання з `ExpiresIn=300`.
4. Відкрийте посилання в браузері без входу в AWS та перевірте вміст.
5. Поясніть, чому не потрібно вимикати Block Public Access або робити об'єкт публічним.
   Посилання може перестати працювати раніше, якщо тимчасові credentials завершаться.
