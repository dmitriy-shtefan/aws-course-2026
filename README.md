# AWS Course 2026

Навчальні матеріали курсу зі створення хмарних рішень за допомогою Amazon Web Services (AWS).

## Матеріали курсу

### Заняття 1. Вступ до хмарних обчислень та AWS

Теми заняття:

- основи хмарних обчислень;
- моделі хмарних сервісів: IaaS, PaaS і SaaS;
- типи розгортання хмари: public, private і hybrid cloud;
- ключові переваги AWS: гнучкість, еластичність, висока доступність і оплата за використання;
- базові поняття хмарної економіки.

- [Приклади запитань AWS Cloud Practitioner](заняття_1/Certification_Questions_Samples.md)

### Заняття 2. Безпека та керування доступом (IAM)

Теми заняття:

- IAM-користувачі та групи;

- багатофакторна автентифікація MFA;
- аудит подій за допомогою AWS CloudTrail.

## Як працювати з матеріалами

1. Опрацюйте презентацію до заняття.
2. Виконайте практичні завдання під час заняття.
3. Перевірте розуміння теми за допомогою тестових запитань.
4. Виконайте та здайте домашнє завдання відповідно до вимог у файлі.

## Важливо

Не додавайте до репозиторію AWS access keys, secret access keys, паролі та інші конфіденційні дані.
