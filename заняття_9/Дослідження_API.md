# Міні-завдання: дослідження API

Оберіть одне з API:

- [Dog API](https://dog.ceo/dog-api/)
- [TVmaze API](https://www.tvmaze.com/api)
- [Open-Meteo API](https://open-meteo.com/en/docs)

За допомогою браузера, Postman або іншого зручного інструмента дослідіть обране API.

1. Виконайте один успішний запит і визначте код статусу HTTP.
2. Знайдіть у JSON-відповіді три корисні поля. Коротко поясніть їх.
3. Змініть шлях запиту або один із параметрів запиту. Порівняйте результат із попередньою відповіддю та поясніть, що змінилося.
4. Запитайте ресурс, якого не існує, або використайте некоректне значення параметра. Перевірте код статусу та тіло відповіді.
5. Запропонуйте ідею невеликого застосунку, який міг би використовувати це API.

## Результат

Будьте готові коротко розповісти (або надайте відповідь письмово):

- яке API ви обрали;
- які запити виконали;
- які коди статусу та поля JSON побачили;
- як змінилася відповідь після зміни шляху або параметра;
- яку ідею застосунку запропонували.
