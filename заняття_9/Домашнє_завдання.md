# REST API для керування нотатками за допомогою API Gateway, AWS Lambda і DynamoDB

Створіть Lambda-функцію на Python для REST API, яка отримує proxy-події від API Gateway, створює нотатки та повертає збережені нотатки за їхнім ідентифікатором.

API має підтримувати два запити:

- `POST /notes` — створення нової нотатки;
- `GET /notes/{id}` — отримання нотатки за її ідентифікатором.

Приклад тіла запиту `POST /notes`:

```json
{
  "id": "note-101",
  "title": "Підготуватися до AWS",
  "text": "Повторити API Gateway і Lambda proxy integration"
}
```

Вимоги:

1. Реалізуйте функцію `lambda_handler(event, context)`.
2. Визначайте HTTP-метод за полем `event["httpMethod"]`.
3. Для `POST /notes` перетворіть `event["body"]` з JSON-рядка на Python-словник.
4. Перевірте наявність і непорожні значення полів `id`, `title` та `text`.
5. Додайте до нотатки дату створення та збережіть її в таблиці DynamoDB з Partition Key `id`.
6. Не перезаписуйте нотатку, якщо такий `id` уже існує.
7. Для `GET /notes/{id}` отримайте `id` з `event["pathParameters"]` і знайдіть відповідну нотатку в DynamoDB.
8. Повертайте відповідь у форматі Lambda proxy integration: поля `statusCode`, `headers` і `body`, де `body` є JSON-рядком. 
9. Використайте відповідні коди HTTP:
    - `201` — нотатку створено;
    - `200` — нотатку знайдено;
    - `400` — некоректне тіло запиту або відсутні обов'язкові поля;
    - `404` — нотатку не знайдено;
    - `409` — нотатка з таким `id` уже існує;
    - `405` — HTTP-метод не підтримується.

Для перевірки функції підготуйте щонайменше чотири тестові події:

- коректний `POST /notes`;
- `POST /notes` без одного з обов'язкових полів;
- `GET /notes/{id}` для наявної нотатки;
- `GET /notes/{id}` для неіснуючої нотатки.

Результат надішліть у вигляді одного файлу:

- `lambda_function.py` — код Lambda-функції.

Перевірка через API Gateway і Postman або `curl` в AWS-акаунті є бажаною, але не обов'язковою. 
Достатньо написати код функції та перевірити його за допомогою тестових подій Lambda.

Не записуйте AWS Access Key, Secret Access Key, Session Token, назву таблиці або API-ключ безпосередньо в коді.
