# Домашнє завдання 03. AWS Console, CLI та SDK

## Завдання

Використайте навчальне середовище **Lab - 1 Introduction to AWS IAM**.

1. Налаштуйте три окремі профілі AWS CLI для IAM-користувачів `user-1`, `user-2` і `user-3`.
   Використовуйте лише облікові дані, доступні в лабораторній роботі. Для всіх профілів
   виберіть us-east-1 регіон.
2. Для кожного профілю перевірте, від імені якого користувача виконуються запити
   (`aws sts get-caller-identity`). Через **AWS CLI** перевірте доступ до:
   - Amazon S3: перегляд списку бакетів (`aws s3 ls`);
   - Amazon EC2: перегляд інстансів (`aws ec2 describe-instances`);
   - Amazon EC2: запуск і зупинка навчального інстансу
     (`aws ec2 start-instances` і `aws ec2 stop-instances`).
3. Напишіть Python-скрипт з **boto3**, який виконує ті самі перевірки окремо для
   `user-1`, `user-2` і `user-3` через `boto3.Session(profile_name=...)`.
   Для кожної дії виведіть назву профілю, результат або назву помилки доступу.

Порівняйте результати трьох користувачів: які дії дозволені, а які повертають `AccessDenied`.
Відмова в доступі — очікуваний результат перевірки прав; зафіксуйте її.

## Що здати

- Python-файл із кодом перевірок через boto3 для всіх трьох профілів.
- Скріншот або кілька скріншотів термінала з командами AWS CLI та результатами для
  `user-1`, `user-2` і `user-3`: ідентичність, S3, перегляд EC2, запуск і зупинка.
  На них мають бути видні успішні відповіді або повідомлення про відмову в доступі.
