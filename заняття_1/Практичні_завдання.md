# Вступ до хмарних обчислень та AWS

### Завдання 1. Сайт мережі кав'ярень

Невелика мережа кав'ярень хоче запустити простий сайт із меню, адресами точок 
і новинами. У компанії зараз сайту немає. Керівник не хоче купувати 
власний сервер і хоче запустити сайт швидко. Також важливо, щоб сайт був доступний 
клієнтам завжди і міг витримувати зростання відвідуваності під час свят.

Дайте відповіді на запитання:

1. Чому для цієї компанії хмара підходить краще, ніж власний сервер?
2. Що краще вибрати для цієї ситуації: IaaS, PaaS або SaaS?
3. Який тип хмари краще підходить: public cloud, private cloud або hybrid cloud?
4. Які 3 переваги хмари найбільш важливі для цієї компанії?
5. Яку коротку рекомендацію ви б дали керівнику? (підсумок 1-4)

### Завдання 2. Внутрішня система навчального центру

Невеликий навчальний центр хоче запустити внутрішню систему для співробітників. 
У системі мають зберігатися списки студентів, розклад занять і службові документи. 
Доступ до системи потрібен тільки адміністраторам і викладачам. Керівник хоче 
відмовитися від зберігання всіх даних на одному офісному комп'ютері, але водночас 
переживає через безпеку інформації.

Дайте відповіді на запитання:

1. Чому в цій ситуації компанії варто розглянути хмарне рішення?
2. Що краще підходить для цієї ситуації: IaaS, PaaS або SaaS?
3. Який тип хмари краще обрати: public cloud, private cloud або hybrid cloud?
4. Які 3 переваги хмари найбільш важливі саме для цієї ситуації?
5. Яку коротку рекомендацію ви б дали керівнику? (підсумок 1-4)

### Завдання 3. Інфраструктура приватної медичної лабораторії

Приватна медична лабораторія хоче перенести свою внутрішню систему зберігання 
результатів аналізів з одного офісного сервера на більш сучасну інфраструктуру. 
Доступ до системи потрібен тільки співробітникам лабораторії. Керівник вимагає 
максимального контролю над даними і не хоче, щоб медична інформація зберігалася 
в загальному публічному середовищі. При цьому компанії потрібні віртуальні 
обчислювальні ресурси і централізоване зберігання даних.

Дайте відповіді на запитання:

1. Чому в цій ситуації компанії варто розглянути хмарне рішення?
2. Що краще підходить для цієї ситуації: IaaS, PaaS або SaaS?
3. Який тип хмари краще обрати: public cloud, private cloud або hybrid cloud?
4. Які 3 переваги хмари найбільш важливі саме для цієї ситуації?
5. Яку коротку рекомендацію ви б дали керівнику?
