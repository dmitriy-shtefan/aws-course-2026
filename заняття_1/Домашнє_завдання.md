### Завдання. Вебпортал для оптової торгової компанії

Оптова торгова компанія вже використовує внутрішню систему обліку товарів 
і замовлень, яка встановлена в офісі і працює тільки для співробітників. 
Тепер компанія хоче запустити новий вебпортал для клієнтів, щоб вони могли 
переглядати каталог і залишати заявки онлайн. Повністю переносити внутрішню 
систему в хмару керівництво поки що не готове, але новий портал потрібно 
запустити швидко і без купівлі додаткових серверів.

Дайте відповіді на запитання:

1. Чому в цій ситуації компанії варто розглянути хмарне рішення?
2. Що краще підходить для цієї ситуації: IaaS, PaaS або SaaS?
3. Який тип хмари краще обрати: public cloud, private cloud або hybrid cloud?
4. Які 3 переваги хмари найбільш важливі саме для цієї ситуації?
5. Яку коротку рекомендацію ви б дали керівнику? (підсумок 1-4)
